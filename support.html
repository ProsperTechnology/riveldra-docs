Contact Riveldra support

Send your theme question privately to Prosper Technologies. Include the steps that reproduce the problem and your theme version.

Private support is active. You will receive an email acknowledgement after submitting. You can also email StableAI@gmx.com.

PNG, JPG or WebP; maximum 10 MB. Remove customer information from screenshots.

Your message and optional screenshot are processed by FormSubmit and delivered to Prosper Technologies at StableAI@gmx.com. Never include passwords, access tokens or customer payment information.

Report a reproducible bug

The public GitHub issue tracker is open for non-sensitive development reports. A GitHub account is required to submit a report there. Include the theme version, browser, steps to reproduce and expected/actual behavior. Add a screenshot only if it contains no private information.

Support scope

This channel currently covers reproducible Riveldra theme behavior. General Shopify account, billing and checkout-platform questions belong with Shopify Help. Compatibility records, product claims and merchant-supplied documents should be confirmed with the store that maintains them.

About this documentation site

These pages run as a static GitHub Pages site. Prosper Technologies has not added analytics or advertising trackers. The support form uses FormSubmit for message delivery, screenshot handling, spam protection and acknowledgement emails. External GitHub, Shopify and FormSubmit services have their own terms and privacy practices. See GitHub Pages data collection.
