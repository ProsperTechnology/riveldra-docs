Report a reproducible bug

The public GitHub issue tracker is open for non-sensitive development reports. A GitHub account is required to submit a report there. Include the theme version, browser, steps to reproduce and expected/actual behavior. Add a screenshot only if it contains no private information.

Private merchant support is not open yet.

This pre-release support page does not yet provide a private contact form, ticket delivery or an automatic acknowledgement service. Those remain launch requirements. Do not post store credentials, access tokens, customer data or private orders in public issues.

Support scope

This channel currently covers reproducible ForgePro theme behavior. General Shopify account, billing and checkout-platform questions belong with Shopify Help. Compatibility records, product claims and merchant-supplied documents should be confirmed with the store that maintains them.

About this documentation site

These pages run as a static GitHub Pages site. Prosper Technologies has not added analytics, advertising trackers, cookies or a submission form here. External GitHub and Shopify services have their own terms and privacy practices. See GitHub Pages data collection.
