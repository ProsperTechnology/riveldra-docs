RIVELDRA / TECHNICAL PRODUCT DATASHOPIFY THEME

Help buyers verify the details.

The theme displays information you maintain in Shopify. It does not create definitions or certify engineering compatibility.

Data compatibility

The forgepro namespace is retained from the first build so existing product records continue to work. Use the keys documented below for Riveldra 0.9.1.

Specification rows and dynamic sources

  1. Create suitable product metafields in Shopify admin, such as model number, material or dimensions.
  2. Add a Technical specifications section to the product template.
  3. Add a row with a clear label and connect its value to a compatible dynamic source, or enter the value manually.
  4. Include units and preview long values and empty fields.

Dynamic sources connect to section and block settings. They are not general theme settings.

Optional selected-variant values

Create a variant metafield in namespace forgepro, for example key bore. Enter bore in that specification row’s Variant metafield key setting. A populated selected-variant value overrides the row’s configured product/manual value; otherwise the configured value remains.

Use an appropriate printable field type and verify each variant. The theme does not infer a dimension from a product option label.

A concise card specification

The optional single-line product metafield forgepro.card_spec supplies one useful detail on a product card, such as 20 × 47 × 14 mm.

Equipment compatibility records

  1. Create a merchant-owned metaobject definition, for example forgepro_compatibility.
  2. Add text fields with exact keys manufacturer, model, part_reference and notes.
  3. Enable appropriate storefront access and make the entries available for storefront use.
  4. Create product metafield forgepro.compatibility as a list of metaobject references restricted to that definition.
  5. Attach verified records to products and add Equipment compatibility to the template.

The optional filter searches only the records rendered for the current product. It does not query external databases or provide universal equipment matching. Products without records show no compatibility claim.

Manuals, drawings and other documents

  1. Create a merchant-owned metaobject definition, for example forgepro_document.
  2. Add fields title (text), category (text) and file (a suitable file reference).
  3. Enable appropriate storefront access.
  4. Create product metafield forgepro.documents as a list of references to that definition.
  5. Upload documents to Shopify Files, create records and attach them to products.

Only entries with a supported file URL are rendered. Manual document-link blocks are also available. A browser may preview the file; forced download is not guaranteed. Use documents you have permission to distribute.

Native commerce boundaries

Quantity rules and price breaks are displayed when Shopify supplies them in the current customer context. Selling plans, B2B company locations, pickup and accelerated checkout depend on real store configuration and eligibility. Riveldra does not recreate checkout or grant plan-restricted functionality.

Verify the data in your store

Test storefront access, empty entries, long values, file links and variant changes. Keep equipment records accurate. Technical claims and compatibility decisions remain the merchant’s responsibility.
