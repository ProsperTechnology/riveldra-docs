FORGEPRO / FAQSHOPIFY THEME

Useful answers, close at hand.

Common setup questions for the first ForgePro build.

Is ForgePro ready for the Shopify Theme Store?

No. Version 0.9.0 is a pre-release candidate. Real Shopify testing, a fully operational private support contact form, demo preparation and final review are still required. No Theme Store approval or measured Lighthouse scores are claimed.

Does the theme include a compatibility database?

No. It renders merchant-maintained product records. The search field filters the displayed records for that product only.

Why is a specification or document missing?

Check the field keys, storefront access, record availability and product assignment. Empty values and invalid file entries are hidden. A row needs a configured value or a populated selected-variant override.

Why are collection filters missing?

Configure eligible filters in Shopify and confirm that the selected collection/search context exposes them. Also check that the theme’s filter/sort setting is enabled.

Does ForgePro require an app?

The core theme does not depend on an app backend. Store-specific features such as selling plans or complementary-product configuration may need Shopify features or merchant integrations. App blocks are supported.

Can customers add products without JavaScript?

The product and cart controls are native Shopify forms, and option values have real navigation URLs. Real-store testing is still required to verify every relevant product scenario.

Does this version include a cart drawer?

No. The first build uses a responsive full cart page with native updates, removals, notes and checkout.

Are other languages included?

Only English is supplied and reviewed in this build. Labels are localized in the theme’s locale file. Additional translations, real currency contexts and RTL layouts need verification.

Can I download the commercial theme here?

No. This repository and website contain public documentation only. Theme source and evaluation packages are distributed separately by Prosper Technologies.

How should I report a bug?

Use the support page for the current channel and reporting guidance. Public reports should contain a minimal reproduction and no private store or customer information.
