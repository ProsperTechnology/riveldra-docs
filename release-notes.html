Version history for ForgePro by Prosper Technologies.

0.9.0 Pre-release · 7 November 2026

The first original local theme build, intended for Shopify test-store evaluation.

Added

  • Industrial visual system with paper, navy and gray color schemes.
  • Requested storefront page templates, including password and gift card.
  • Product option-value navigation, SKU/price/availability output and native purchase forms.
  • Native filters, sorting, predictive search and grid/list presentation.
  • Technical specifications, variant overrides, scoped equipment records and document links.
  • Configurable home-page and content sections, plus related/complementary recommendation output.

Validation so far

Nine local interaction checks passed and 13 adapted template fixtures rendered without duplicate IDs or unlabeled fields. A limited axe-core scan of eight local fixtures reported no violations; incomplete checks and contrast still require further review. These are local results, not live Shopify commerce tests or accessibility certification.

Before a commercial release

Complete Shopify installation/editor/commerce testing, representative performance measurement, browser and screen-reader checks, a real demo store, private support operations and final commercial review. ForgePro remains an uncleared working name.

Updating a test installation

Duplicate your unpublished test theme before changing files. Preserve merchant settings, template configuration and data definitions. No prior commercial-installation migration is claimed for this candidate.
