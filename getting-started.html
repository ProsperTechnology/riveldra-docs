RIVELDRA / GETTING STARTEDSHOPIFY THEME

A clear path to your first preview.

Configure an unpublished test copy before changing a live storefront.

1. Prepare a Shopify test store

Use a store under your control with access to Online Store themes. Keep the existing live theme intact and work in a separate unpublished copy. Version 0.9.4 has passed core live Shopify checks but remains a test candidate while the full release matrix is completed.

2. Upload the theme-only ZIP

Use the theme ZIP supplied by Prosper Technologies. Its root contains assets, config, layout, locales, sections, snippets and templates. The complete development-project ZIP is a separate package and must not be uploaded as a theme.

After upload, choose Customize or preview the unpublished theme. Successful installation still needs to be confirmed on Shopify for this pre-release.

3. Set your identity and menus

  1. In theme settings, choose your fonts, color schemes, page width and favicon.
  2. In Header, upload a logo and select the main menu.
  3. In Footer, add your business description and choose a footer menu.
  4. Create real collection and resource links in Shopify navigation.

4. Prepare products and collections

Add products, variants, images, prices and inventory in Shopify. Create department collections and configure eligible filters with Shopify’s supported filtering controls. Riveldra displays the filter data Shopify supplies; it does not create filter definitions.

The optional sample CSV is intended for a test store. Upload sample illustrations manually; a local file path in a CSV does not create a Shopify-hosted product image.

5. Build your home page

Choose actual collections in Featured collections and Featured products. Replace instructional text with your own copy. Set hero content and link each action to a real collection, page or file. Optional buttons remain hidden until a destination is configured.

6. Configure the product template

Keep Title, Price, Variant picker and Buy buttons visible. Add Description, Pickup availability, collapsible information and other relevant blocks. Accelerated checkout is enabled by default and is generated by Shopify. Connect technical product data where needed.

7. Add content pages

Assign the page.contact template to your contact page. Create standard pages, a blog and articles as needed. Password and gift-card templates are included. This version uses Shopify’s hosted customer-account destination; custom legacy account templates are not included.

8. Verify before publishing

Test actual product variants, add-to-cart, quantity changes, discounts, checkout, filters, forms, mobile layouts and keyboard navigation. Confirm all links and images. Store-specific features such as pickup, selling plans and B2B need their own eligible test scenarios. Do not publish this pre-release as production-ready without completing the release checks.
